function HasAlphaDigits(W: integer): boolean;
{test if number has A..F in one or more of the digits}
{Only works for numbers up to 9FF or 2559}
begin
Result:=((W and $000F) in [$000A,$000B,$000C,$000D,$000E,$000F]) or
   ((W and $00F0) in [$00A0,$00B0,$00C0,$00D0,$00E0,$00F0]);
end;

## Memory game approach in maXbox

The documented approach uses a `TStringGrid`/`TDrawGrid` (or `QGrid` on Linux/CLX) filled with bitmap 
images to represent cards.  The basic structure follows a typical game loop: 
[sourceforge](https://sourceforge.net/p/maxbox/wikimax/maxbox_mainwiki/)

1. **Configure and open window** – create the form and grid
2. **Initialize resources** – load card images, shuffle pairs
3. **Register input callbacks** – handle mouse clicks on grid cells
4. **Event processing loop** – manage game state (flipping, matching, scoring) 
[softwareschule](http://www.softwareschule.ch/download/maxbox_starter7.pdf)
