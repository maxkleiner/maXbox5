Bayes' Theorem Precision Formula:
$$\text{Precision} = \frac{\text{Recall} \times \text{Prevalence}}{(\text{Recall} \times \text{Prevalence}) + (\text{FPR} \times (1 - \text{Prevalence}))}$$
Note: When Prevalence is small ($1\%$), false alarms from the large negative population ($99\%$) dilute precision despite low FPR [4, 5].

2. Standalone Python Script

You can run this Python script using scikit-learn, numpy, and pandas to perform the exact same Bayesian precision conversion [1]:

import numpy as np
import pandas as pd
from sklearn.metrics import confusion_matrix, classification_report

def bayes_precision(recall, fpr, prevalence):
    """Calculates Bayesian Precision (Posterior) from confusion matrix rates."""
    numerator = recall * prevalence
    denominator = (recall * prevalence) + (fpr * (1.0 - prevalence))
    return numerator / denominator

# --- Case Study Parameters ---
population = 10000
prevalence = 0.01   # 1% positive class prevalence [4]
recall = 0.90       # 90% Recall (True Positive Rate) [4]
fpr = 0.05          # 5% False Positive Rate [4]

# 1. Calculate Theoretical Matrix Counts
actual_positives = int(population * prevalence)       # 100 [5]
actual_negatives = population - actual_positives      # 9,900 [5]

tp = int(actual_positives * recall)                  # 90 [5]
fn = actual_positives - tp                            # 10 [5]
fp = int(actual_negatives * fpr)                      # 495 [5]
tn = actual_negatives - fp                            # 9,405 [5]

# 2. Reconstruct Labels for Scikit-Learn Evaluation
y_true = np.array([1]*tp + [1]*fn + [0]*fp + [0]*tn)
y_pred = np.array([1]*tp + [0]*fn + [1]*fp + [0]*tn)

# 3. Compute Confusion Matrix
cm = confusion_matrix(y_true, y_pred)
cm_df = pd.DataFrame(cm, 
                     index=['Actual Negative (0)', 'Actual Positive (1)'],
                     columns=['Pred Negative (0)', 'Pred Positive (1)'])

# 4. Compare Empirical vs Bayesian Precision
empirical_precision = tp / (tp + fp)
bayes_posterior = bayes_precision(recall, fpr, prevalence)

print("=== CONFUSION MATRIX DATA FRAME ===")
print(cm_df)
print(f"\nEmpirical Precision : {empirical_precision:.2%}")
print(f"Bayesian Posterior  : {bayes_posterior:.2%}")
print("\n=== CLASSIFICATION REPORT ===")
print(classification_report(y_true, y_pred, target_names=['Negative', 'Positive']))
